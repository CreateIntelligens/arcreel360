# 劇集工作區三階段拆分 + 原文並排 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 把 `TimelineCanvas` 的兩 tab（預處理/時間線）重構成三階段 tab（預處理→分鏡圖→影片），三階段共用同一批 segment panel 且切 tab 保持滾動位置，並在分鏡圖/影片 tab 旁並排對照原文（Step 1 段落）。

**Architecture:** 前端為主的重構。`TimelineCanvas` 的 `activeTab` 從 `"preprocessing" | "timeline"` 三態化為 `"preprocessing" | "storyboard" | "video"`；`SegmentCard` 接收 `stage` prop 按階段過濾分鏡圖/影片區塊；原文側欄複用既有 `GET /drafts/{episode}/step1` API（無需新後端端點）；頂層 `GlobalHeader` phase 跳轉帶上目標 tab。資料模型完全不變。

**Tech Stack:** React 19 + TypeScript + Tailwind CSS 4，`@tanstack/react-virtual`（既有虛擬滾動），wouter 路由，zustand store，vitest（前端測試 `pnpm check`）。

- [ ] **Step 4: 實作 SourceTextPanel**

```tsx
import { useState } from "react";
import { API } from "@/api";
import { StreamMarkdown } from "@/components/ui/StreamMarkdown"; // 對齊 PreprocessingView 用的 markdown 元件

interface SourceTextPanelProps {
  projectName: string;
  episode: number;
}

/**
 * 原文對照側欄：讀預處理 Step 1 段落（narration→step1_segments.md /
 * drama→step1_normalized_script.md），供使用者對照分鏡是否貼合原著。
 * 唯讀、預設收合，避免擠壓 segment panel 寬度。
 */
export function SourceTextPanel({ projectName, episode }: SourceTextPanelProps) {
  const [open, setOpen] = useState(false);
  const [content, setContent] = useState<string | null>(null);
  const [loading, setLoading] = useState(false);

  const toggle = async () => {
    const next = !open;
    setOpen(next);
    if (next && content === null) {
      setLoading(true);
      try {
        const result = await API.getDraftContent(projectName, episode, 1);
        setContent(typeof result === "string" ? result : (result?.content ?? ""));
      } catch {
        setContent("");
      } finally {
        setLoading(false);
      }
    }
  };

  return (
    <aside className="shrink-0 border-l border-gray-700">
      <button
        type="button"
        onClick={() => void toggle()}
        className="px-2 py-1 text-xs text-gray-400 hover:text-white"
      >
        原文 {open ? "▸" : "◂"}
      </button>
      {open && (
        <div className="w-[18rem] max-w-[30vw] overflow-auto p-3 text-sm">
          {loading ? (
            <p className="text-gray-500">載入中…</p>
          ) : content ? (
            <StreamMarkdown content={content} />
          ) : (
            <p className="text-gray-500">尚無原文（尚未預處理此集）</p>
          )}
        </div>
      )}
    </aside>
  );
}
```

> `result` 形狀依 Step 1 確認結果調整（字串 or `{content}`）。`StreamMarkdown` import 路徑對齊 `PreprocessingView.tsx` 的 import（grep 確認）。寬度用 `rem`/`vw` 相對單位，符合專案 px 規範。
