# 拆段時自動按集數均分原文 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 拆段（及劇集規範化）某集時：使用者有指定原文來源就用指定的；沒指定，就自動把 `source/` 整本原文按 `project.json` 的集數平均切分，取該集對應的那一段——使用者不需操作「分集」步驟。

**Architecture:** 在 `lib/episode_splitter.py` 新增純函式 `split_into_n_episodes(text, total_episodes)`，用既有的 `count_chars` / `find_char_offset` / `find_natural_breakpoints` 把整本原文按字數均分為 N 段、切點落最近句末標點。在兩支預處理腳本的 `resolve_novel_text()` 內，當某集缺專屬原文且使用者未指定 `source` 時，呼叫此函式取該集片段。「整本原文」= `source/` 內所有文字檔（排除 `_remaining.txt`）按檔名排序串接。HTTP 端與前端新增「指定來源」的可選參數，讓使用者能覆寫自動均分。

**Tech Stack:** Python 3.13、pytest（`asyncio_mode=auto`）、ruff；前端 React 19 + TypeScript。`split_into_n_episodes` 為純函式（無 I/O）。

## 背景與設計決策

### 使用者意圖（本計畫的依據）

- 「拆段時自動從整本按集數分」——沒指定來源時的預設行為。
- 「還是要給用戶指定來源——沒指定就這樣（均分），有指定就用指定的」——`source` 為可選覆寫。
- 「整本原文」= `source/` 內所有檔按檔名串接。
- 「共幾集」= `project.json` 現有 `episodes` 數量。
- narration 與 drama 兩模式行為一致。

### 現況

`resolve_novel_text(project_path, episode, source)`（本 session 已修）目前邏輯：有 `source` → 讀該檔；`episode_N.txt` 存在 → 讀它；`episode==1` 單章 fallback；否則 `raise SourceNotReadyError`。

`resolve_novel_text` 的 `source` 參數**機制上已支援指定來源**，但：
- 拆段腳本 `--source` CLI 參數已存在。
- `lib/episode_preprocess.run_preprocess()` 呼叫腳本時**寫死不帶 `--source`**（`["--episode", str(episode)]`）。
- HTTP 路由 `preprocess_episode` 與前端拆段按鈕**沒有傳遞 `source` 的能力**。

因此「有指定就用指定」要打通的是 **run_preprocess → 路由 → 前端** 這條傳遞鏈，而非 `resolve_novel_text` 本身。

### 設計邊界（明確不做）

- **不改既有分集切分流程**：`commit_episode_split` / split 路由 / `split_episode.py` / `_remaining.txt` 機制一律不動。它們仍可用（進階手動精切），其產物 `episode_N.txt` 優先序高於均分。
- **不新增 `project.json` 欄位**。
- **均分不寫檔**：拆段當下即時計算，不落地 `episode_N.txt`（落地會與動態集數衝突）。

### 已知取捨（使用者已確認接受）

- **動態分母**：集數來源為 `project.json` 現有 `episodes` 數量。新增第 N+1 集後分母改變，已拆過舊集的「均分起迄」會位移、內容隨之改變。使用者已選此行為。因拆段本就是「重新拆段」可重跑，影響可控。
- **集的順序**：以 `episode` 數字升序決定「第幾段」。`resolve_novel_text` 內以「該集在升序集列表中的 1-based 索引」對應段落（索引而非裸 `episode` 值，故集號不連續也正確）。

### 與已修 bug 的關係

本 session 已完成「拆段缺原文 → HTTP 400 + 清楚訊息」修復（`SourceNotReadyError`、退出碼 3、路由 400、drama 對齊、前端文案去術語）。本計畫建立在其上。修畢後 `SourceNotReadyError` 僅在「`source/` 完全沒有原文檔或內容為空、且未指定 `source`」時才拋。

def split_into_n_episodes(text: str, total_episodes: int) -> list[str]:
    """把整本原文按有效字數均分為 total_episodes 段，切點落最近句末標點。

    供「拆段時自動按集數均分原文」使用：不需錨點、不需使用者指定切點。
    保證 "".join(回傳值) == text（不丟字、不重複）。

    Args:
        text: 整本小說原文。
        total_episodes: 目標段數（= project.json 的集數），須 >= 1。

    Returns:
        長度為 total_episodes 的字串列表，依序為第 1..N 段。
        當內容過短不足以切出 N 段時，末尾段可能為空字串。

    Raises:
        ValueError: total_episodes < 1。
    """
    if total_episodes < 1:
        raise ValueError(f"集數必須 >= 1，得到 {total_episodes}")
    if total_episodes == 1:
        return [text]

    total = count_chars(text)
    cut_offsets: list[int] = []
    for k in range(1, total_episodes):
        target_chars = round(total * k / total_episodes)
        raw_offset = find_char_offset(text, target_chars)
        breakpoints = find_natural_breakpoints(text, raw_offset, window=200)
        sentence_bps = [bp for bp in breakpoints if bp["type"] == "sentence"]
        chosen = sentence_bps or breakpoints
        offset = chosen[0]["offset"] if chosen else raw_offset
        cut_offsets.append(offset)

    # 切點需單調遞增且落在 [0, len(text)]，避免重疊或越界。
    cut_offsets = sorted(min(max(o, 0), len(text)) for o in cut_offsets)

    parts: list[str] = []
    prev = 0
    for offset in cut_offsets:
        parts.append(text[prev:offset])
        prev = offset
    parts.append(text[prev:])
    return parts
```

說明：`count_chars`、`find_char_offset`、`find_natural_breakpoints` 皆為本檔既有函式。`find_natural_breakpoints` 回傳項含 `offset` 與 `type`（`"sentence"`／`"paragraph"`）。

def _episode_source_files(source_dir: Path) -> list[Path]:
    """列出 source/ 內可視為小說原文的檔案（排除分集切分產生的 _remaining.txt）。"""
    if not source_dir.is_dir():
        return []
    return sorted(
        f
        for f in source_dir.iterdir()
        if f.is_file() and f.suffix.lower() in _SOURCE_SUFFIXES and f.name != "_remaining.txt"
    )


def _read_whole_source(source_dir: Path) -> str:
    """把 source/ 內所有原文檔按檔名排序串接成「整本原文」。"""
    files = _episode_source_files(source_dir)
    return "\n\n".join(f.read_text(encoding="utf-8") for f in files)


def _episode_index_and_total(project_path: Path, episode: int) -> tuple[int, int]:
    """從 project.json 算出 (該集在升序集列表中的 1-based 索引, 總集數)。

    project.json 不存在 / 無 episodes / 該集不在列表 → 退化為 (1, 1)，
    亦即把整本當單一一集，確保仍可拆段。
    """
    import json as _json

    project_json = project_path / "project.json"
    if not project_json.exists():
        return (1, 1)
    try:
        data = _json.loads(project_json.read_text(encoding="utf-8"))
    except (ValueError, OSError):
        return (1, 1)
    episodes = data.get("episodes") or []
    numbers = sorted(
        int(ep["episode"]) for ep in episodes if isinstance(ep, dict) and "episode" in ep
    )
    if not numbers or episode not in numbers:
        return (1, 1)
    return (numbers.index(episode) + 1, len(numbers))


def resolve_novel_text(project_path: Path, episode: int, source: str | None) -> str:
    """決定並讀取某集的小說原文。

    解析順序：
    1. 使用者指定 source → 讀該檔（覆寫自動均分）。
    2. source/episode_{episode}.txt 存在 → 讀它（進階使用者手動精切的產物）。
    3. 否則 → 讀 source/ 整本原文，按 project.json 的集數均分，取本集那一段。

    Raises:
        ValueError: 指定的 source 路徑超出專案目錄。
        FileNotFoundError: 指定的 source 檔不存在。
        SourceNotReadyError: 未指定 source 且 source/ 內無原文檔／整本內容為空。
    """
    if source:
        project_root = project_path.resolve()
        source_path = (project_path / source).resolve()
        if not source_path.is_relative_to(project_root):
            raise ValueError(f"路徑超出專案目錄: {source_path}")
        if not source_path.exists():
            raise FileNotFoundError(f"未找到原始檔: {source_path}")
        return source_path.read_text(encoding="utf-8")

    candidate = project_path / "source" / f"episode_{episode}.txt"
    if candidate.exists():
        return candidate.read_text(encoding="utf-8")

    whole = _read_whole_source(project_path / "source")
    if not whole.strip():
        raise SourceNotReadyError(
            "source/ 內沒有可用的小說原文。請先在資產面板上傳小說原文檔，再執行拆段。"
        )

    from lib.episode_splitter import split_into_n_episodes

    index, total = _episode_index_and_total(project_path, episode)
    parts = split_into_n_episodes(whole, total)
    return parts[index - 1]
```

@router.post("/projects/{name}/episodes/{episode}/preprocess")
async def preprocess_episode(
    name: str,
    episode: int,
    _user: CurrentUser,
    req: PreprocessEpisodeRequest = PreprocessEpisodeRequest(),
):
    """Step 1 預處理：根據 content_mode 呼叫對應 skill 腳本。

    req.source 可選：指定本集原文來源；省略則自動按集數均分整本原文。
    """
    from lib.episode_preprocess import SourceNotReadyError, run_preprocess

    try:
        manager = get_project_manager()
        if not manager.project_exists(name):
            raise HTTPException(status_code=404, detail=f"專案 '{name}' 不存在")

        project = await asyncio.to_thread(manager.load_project, name)
        project_path = manager.get_project_path(name)
        with project_change_source("webui"):
            return await asyncio.to_thread(
                run_preprocess,
                project_path,
                episode,
                content_mode=project.get("content_mode", "narration"),
                repo_root=PROJECT_ROOT,
                source=req.source,
            )

    except SourceNotReadyError as e:
        raise HTTPException(status_code=400, detail=str(e))
    except ValueError as e:
        raise HTTPException(status_code=400, detail=str(e))
    except (FileNotFoundError, RuntimeError) as e:
        raise HTTPException(status_code=500, detail=str(e))
    except HTTPException:
        raise
    except Exception as e:
        logger.exception("請求處理失敗")
        raise HTTPException(status_code=500, detail=str(e))
