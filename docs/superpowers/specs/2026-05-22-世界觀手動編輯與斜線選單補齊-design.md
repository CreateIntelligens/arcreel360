# 世界觀手動編輯介面 + 斜線選單功能補齊

狀態:Draft
日期:2026-05-22

## 背景

上一個 commit `b5b4dfc` 已為 agent 補上 `generate_overview` / `update_overview`
兩個函式工具,並把後端 PATCH 端點 `PATCH /projects/{name}/overview`、前端
`API.updateOverview()` 都建好了。但仍有兩個缺口:

1. **前端 `OverviewCanvas` 的「專案概述」區塊仍是唯讀**——只顯示
   `synopsis / genre / theme`(連 `world_setting` 都漏顯示),使用者無法手動編輯,
   只能整個「生成」。`API.updateOverview()` 已存在但前端沒有任何 UI 用到它。
2. **對話框 `/` 選單缺少世界觀與場景指令**——`generate_overview` / `generate_scenes`
   是函式工具,沒有對應的 skill 目錄,而 `/` 選單資料源是「掃 skill 目錄」,
   因此這兩個常用意圖無法從選單觸發。

## 目標

- 使用者可在專案概述頁直接手動編輯世界觀四個欄位並儲存。
- `/` 選單補上「生成世界觀」「生成場景」兩個指令,行為與既有 8 個 skill 一致。

## 非目標

- 不改後端 overview 端點與 `ProjectManager`(已存在且可用)。
- 不在 `/` 選單放破壞性操作(`rename_entity` / `delete_entity`)或「改描述」類工具。
- 不改 `/` 選單的互動行為(維持插入 `/skill-name ` + 空格,使用者自行補描述)。

## 第一部分:前端世界觀手動編輯介面

### 範圍

純前端。後端 `PATCH /projects/{name}/overview`(`server/routers/projects.py:1367`)
與 `API.updateOverview()`(`frontend/src/api/projects.ts:222`)皆已存在,直接接用。

### 設計

- 從 `OverviewCanvas.tsx`(目前約 470 行)抽出獨立元件
  `frontend/src/components/canvas/OverviewSection.tsx`,負責「專案概述」區塊。
- 四個欄位皆可手動編輯:
  - `synopsis`、`world_setting` → `textarea`
  - `genre`、`theme` → 單行 `input`
- 沿用同檔「風格描述」既有模式:草稿 state + 髒值偵測 + 僅在改動時顯示「儲存」按鈕。
  儲存呼叫 `API.updateOverview(projectName, patch)`,成功後 `refreshProject()` + toast。
- 「生成」按鈕保留(`API.generateOverview`)。
- 唯讀的退化情況(尚未生成 overview)維持原本提示文案。

### 測試

`OverviewCanvas.test.tsx` 已存在。補:欄位可編輯、髒值才顯示儲存鈕、
儲存呼叫 `updateOverview` 帶正確 patch、`world_setting` 有顯示。

## 第二部分:`/` 選單補齊功能

### 範圍

新增 2 個 skill 目錄,各含 `SKILL.md`。對應的後端函式工具
(`generate_overview`、`generate_scenes`)已在 `skill_function_declarations.py` 實作,
本部分不寫新後端邏輯。

### 設計

- 新增 `agent_runtime_profile/.claude/skills/generate-overview/SKILL.md`
- 新增 `agent_runtime_profile/.claude/skills/generate-scenes/SKILL.md`
- frontmatter 不設 `user-invocable`(預設 `True`),使其自動進入 `/` 選單。
- `SKILL.md` 內容說明該意圖對應的工具與用法,沿用 `generate-characters/SKILL.md` 風格。
- `server/agent_runtime/service.py` 的 `_SKILL_DISPLAY_META` 補兩筆 label + Lucide icon:
  - `generate-overview` → label「生成世界觀」,icon 待定(如 `globe`)
  - `generate-scenes` → label「生成場景」,icon 待定(如 `mountain` / `image`)
- `frontend/src/components/copilot/SlashCommandMenu.tsx` 的 `ICON_MAP` 與
  `SKILL_META_FALLBACK` 同步補上對應 icon 與 fallback label。
- `/` 選單互動行為不變:選取後插入 `/generate-overview `(尾帶空格),
  游標停在後方,使用者可自行補描述,例如 `/generate-overview 偏懸疑風`。

### 分集切分為何不單獨建

`split_episode` / `peek_split_point` 已歸屬 `manage-project` skill,
且 `manage-project` 標記 `user-invocable: false`(屬內部工具集),維持現狀不動。

### 測試

`SlashCommandMenu.test.tsx` 已存在。補:兩個新 skill 出現在選單、
filter 命中、選取插入正確 `/skill-name`。
